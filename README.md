## 🚀 Featured Projects

### 🟢 Smart Public Distribution System *(SIH 2025 Internal Selection)*
> `ESP32` `HX711` `RC522 RFID` `Firebase RTDB` `Embedded C`

Automated ration dispensing system addressing manual fraud and quantity disputes in PDS shops. Dual-ESP32 architecture handles dispensing control and stock monitoring independently, with HX711 load-cell sensing driving weight-verified dispensing. OTP-based beneficiary authentication and transaction-ID validation prevent duplicate claims at the firmware level. Firebase RTDB syncs stock and transaction state to role-based dashboards for beneficiaries, shop owners, and auditors.

🔗 [View Repository](https://github.com/VaishakSCEM543/smart-public-distribution-system)

---

### 🟡 Distributed Swarm-Based Environmental Surveillance System *(Major Project — Ongoing)*
> `ESP32` `GPS` `Ultrasonic Sensors` `Firebase RTDB` `Embedded C`

Multi-node ESP32 sensing system for cooperative environmental monitoring. Each node independently collects ultrasonic and GPS data and reports to a centralized Firebase backend for aggregated monitoring. Currently extending the architecture to handle node dropout and message retry logic.

🔗 [View Repository](https://github.com/VaishakSCEM543/smart-border-surveivalence--system)

---

### 🟢 Embedded Tamper Detection System for Weighing Machines
> `ESP32` `HX711` `Embedded C`

Firmware-level tamper detection for electronic weighing systems using threshold and rate-of-change analysis on HX711 signal output. Flags abnormal weight variation patterns indicative of manipulation and raises serial-logged alerts in real time.

🔗 [View Repository](https://github.com/VaishakSCEM543/ai-enabled-tamper-detection)
