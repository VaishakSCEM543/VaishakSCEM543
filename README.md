## 🚀 Featured Projects

### 🟢 Smart Public Distribution System *(SIH 2025 Internal Selection)*
> `ESP32` `HX711` `RC522 RFID` `Firebase RTDB` `C` `HTML/CSS/JS`

Automated IoT ration dispensing system with **±5g weight accuracy**, RFID beneficiary authentication, and real-time Firebase transaction logging. Built role-based portals for Admin, Distributor, and Beneficiary with duplicate prevention and audit trails. Selected in Smart India Hackathon 2025 Internal Round.

🔗 [View Repository](https://github.com/VaishakSCEM543/smart-public-distribution-system)

---

### 🟡 Distributed Swarm-Based Environmental Surveillance System *(Major Project — Ongoing)*
> `ESP32` `GPS` `Ultrasonic Sensors` `Firebase RTDB` `C`

Multi-node autonomous sensing architecture for cooperative environmental threat detection. Nodes communicate independently with GPS-based location tagging, ultrasonic sensing, and centralized Firebase monitoring. Designed for scalable deployment with fault-tolerant alert generation.

🔗 [View Repository](https://github.com/VaishakSCEM543/smart-border-surveivalence--system)

---

### 🟢 Smart Inventory & Shelf Management System *(Top 10 Finalist — Skill Sangam 2K25)*
> `ESP32` `RC522 RFID` `HX711` `YOLOv5` `C`

Multi-layer inventory verification combining RFID identification over SPI, load-cell weight validation, and YOLOv5 visual confirmation. Achieved **90%+ stock accuracy**. Fully functional prototype delivered within a 24-hour hackathon constraint.

---

### 🟢 Embedded Tamper Detection System for Weighing Machines
> `ESP32` `HX711` `Embedded C`

Real-time tamper detection firmware using threshold and rate-of-change anomaly logic on HX711 weight signals. Detects unauthorized manipulation and generates serial alerts with event reporting.

🔗 [View Repository](https://github.com/VaishakSCEM543/ai-enabled-tamper-detection)
